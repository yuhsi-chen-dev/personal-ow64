# 0003. 追蹤單位：混合型，每項行為各自選

- 狀態：**已被取代**，見 [0008](0008-tracking-taxonomy.md)
- 日期：2026-08-21

## 決策

每一項具體行為自帶 `trackingType`，三選一：

| trackingType | 語意 | 目標值 | 彙總方式 |
|---|---|---|---|
| `daily` | 每日打卡 | 無 | 完成天數 / 統計區間天數；可算連續天數 |
| `count` | 次數累計 | `target`（如 10） | `sum(value) / target` |
| `percent` | 百分比進度 | 固定 100 | 取最新一筆 value |

## 理由

64 項行為的性質天差地遠，強迫用同一種單位會讓一半的格子填得很勉強。

## 後果

資料模型與所有圖表都得處理三種型態。這個複雜度由 [0004](0004-single-log-table.md)
的單表設計、以及「進度公式只能有一份」（見 `../domain.md`）兩條規則壓住。

## 為什麼被取代

`daily` 把分母寫死成「區間內的每一天」，所以每週或每月才做一次的行為永遠顯示成低分。
`percent` 又跟里程碑、累計的語意重疊。而且三類都容不下「銘記在心、不追蹤」那種格子。
改成四類的理由與規則見 [0008](0008-tracking-taxonomy.md)。
