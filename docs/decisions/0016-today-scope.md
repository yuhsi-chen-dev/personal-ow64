# 0016. 今天的分母只算有週期的事

- 狀態：已採納
- 日期：2026-08-25
- 補充 [0008](0008-tracking-taxonomy.md)（四個類型照舊，改的是「今天」怎麼算）

## 問題

今天頁上方的「5 / 6」與那條進度條，分母原本是 `due + done`，
而 `todayState` 把**里程碑與累計也判成 `due`**：

- 里程碑：從沒完成過 → 每一天都是 `due`，直到完成為止。
- 累計：沒到目標 → 每一天都是 `due`，直到達標為止。

所以一格「今年累積跑滿 500 公里」或「參加一場半程馬拉松」，從建立那天起到完成為止，
**每天都佔著今天的分母**。使用者要看到 6/6，得在同一天跑完半馬。

這條進度條的意思應該是「今天結束時我能不能收工」。把一年期的目標放進分母，
等於把終點線移到永遠——**而永遠不會滿的進度條，兩週後就沒有人看了**。
數字沒有壞，但它安靜地在說謊，跟 0008 推翻 0003 是同一種病。

## 決策

**只有「有週期」的事才進今天的分母，也就是只有習慣型。**

這條線跟 0008 的四型定義是同一條：**有 `cadence` 才有「本期」，有本期才有應做量。**
里程碑沒有週期，「今天沒做」根本不算失敗；累計是總量，沒有「今天該加多少」這回事。
既然它們沒有今天的應做量，就不該有今天的分數。

新增一個 `TodayState`：

- `open` — 可以推進，但今天沒有應做量。還沒完成的里程碑、還沒達標的累計。
  **看得到、按得下去，不計分。**

`tally` 只算 `due + done`，`open` 與 `idle`、`mantra` 一樣被排除。

每週／每月習慣**留在分母裡**，因為今天做了就真的完成本期，是能收工的事。

## 今天完成了怎麼算

里程碑或累計**今天真的動了**，狀態是 `done`，會同時進分子與分母（5/6 變成 6/7）。
這是誠實的：它是因為你做了才出現在今天的清單上，不是一直欠著你。

## 後果

- 今天頁的地圖從三階變四階：`due` 最亮、`done` 半亮、`open` 0.3、其餘沉下去。
  `open` 的濃度必須明顯低於 `due`，否則一年期的里程碑會跟今天真的該做的事搶同一個視覺順位。
- 選到 `open` 的格子時，細節卡會明說「這種目標沒有週期，隨時可以推進，不算進今天的數字」。
  不講的話，使用者會按下去、發現上面的數字沒動，以為壞了。
- 只有一格里程碑、其餘都沒填的計劃表，今天頁會顯示「沒有待辦」而不是「0 / 1」。
  這是對的：今天真的沒有它的事。
- **沒有為「今天打算做哪一件長期目標」建模。** 那需要每日計畫（把某個里程碑排進今天），
  是另一個量級的東西。目前的答案是：長期目標永遠可推進、永遠不催你。
  真的要做請開新編號。
