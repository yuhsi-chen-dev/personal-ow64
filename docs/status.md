## 已完成

- Next.js 16 + TypeScript + Tailwind 骨架（`create-next-app`）。
- 領域核心（純函式，不碰 React 也不碰資料庫）：`lib/mandala.ts` 9×9 座標映射、
  `lib/progress.ts` 四型態進度彙總、`lib/day.ts` 當地日期與週期、
  `lib/board.ts` 81 格顯示模型、`lib/palette.ts` 每個次目標的色相、
  `lib/trend.ts` 年度熱圖與月趨勢、`lib/today.ts` 今天該做什麼的判準。
- 資料層：Neon Postgres，`db/schema.ts` 四張表 + 三支 migration，已套用到 Neon。
- 輸入驗證：`lib/schemas.ts`（Zod，照 decisions/0006 的規格）+ `lib/schemas.test.ts`。
- 追蹤方式四類（習慣＋頻率／累計／里程碑／信念），見 `decisions/0008`。
- 寫入路徑：`app/actions.ts` 的 server action（建立計劃表、改核心目標名稱、刪計劃表、
  存次目標、存行為、移除一格、打卡），搭配 `db/queries.ts` 的讀取。
  次目標與行為用 upsert（靠 (planId, position) 與 (subGoalId, position) 的**條件式**唯一索引）；
  同期冪等在 `db/writes.ts` 的 `logOnce` 裡先查再寫，範圍跟著 trackingType 走。
- **移除一格＝封存**：有紀錄的格子只填 `archived_at`，紀錄留著；沒紀錄的才真的刪。
  整份計劃表的刪除是真刪（FK cascade）。規則與理由見 `decisions/0009`。
- 畫面：`/` 是首頁與計劃表清單（每列可刪，兩段式確認，確認那一步列出會失去的次目標／行為／紀錄筆數），
  `/plans/[id]` 是 9×9 熱力圖，點區塊放大（焦點＋小地圖）、點格子開右側面板編輯、
  聚焦後每格底部一條打卡按鈕（含樂觀回饋）；核心格可改名，次目標與行為格可移除。
  統計區間 30／90／一年用網址 `?days=` 切換。
  `/plans/[id]/review` 是回顧頁：年度打卡熱圖（53×7，含已封存格子的紀錄）＋
  整體月趨勢折線 ＋ 八個次目標各一條 sparkline。全部手寫 SVG，沒有圖表套件。
  `/plans/[id]/today` 是每天用的那一頁：同一張 9×9，只把今天要做的格子點亮，
  其餘沉成底色；點格子看它是什麼，下面一顆大按鈕打卡，上面是「今天 3/7」的計數。
  淺色／深色可切換並記住選擇。視覺語言見 `decisions/0007`。四頁都是 `force-dynamic`。
- 登入與資料隔離：Auth.js v5 + Google，session 走 JWT（沒有 users／accounts／sessions
  資料表）。`plans.userId` 存 OAuth subject，其餘三張表往上 join。
  `db/writes.ts` 每一支都吃 `userId`，改動時型別會逼你補上。見 `decisions/0011`。
- 整合測試：`db/write-path.test.ts` 對真實資料庫驗 upsert、同期冪等、改名、
  硬刪與封存的分界、封存過的位置可以重填而且不撿回舊紀錄，
  以及 8 個資料隔離案例（B 拿 A 的 id 打進來會被擋下）。

## 已驗證到哪

寫入路徑在真實資料庫上走過（查資料庫確認，不是看畫面）：結構、讀取、寫入、
upsert 命中條件式唯一索引、同期冪等、改名、硬刪 vs 封存、封存後重填拿到全新的列。

畫面在 Chrome 上實際操作過（2026-08-23）：

- **手機尺寸的破版修掉了**。原因是聚焦格子底部那條打卡按鈕沒有 `whitespace-nowrap`，
  格子窄到約 60 px 時「本週已完成」斷成兩行，整條變兩倍高往上蓋掉標題。
  現在條是固定 `h-7`、字不換行、格子上用短標籤（期間字樣讓給面板），
  而且格子的內容區在條的上緣就收邊——否則沒有底色的「記一次」後面會透出第二行字。
- 順手修掉一個資料 bug：面板原本把點下去當時的 `Cell` 物件存進 state，存檔之後
  拿到的還是舊快照，輸入框留著舊字，再按一次儲存就把剛改好的名字覆蓋回去。
  現在只記「選了哪一格」，每次 render 從新的 board 撈。
- 桌機淺色／深色都看過；建立計劃表 → 改核心目標名稱 → 建次目標 → 移除次目標 →
  刪整份計劃表，整條走完。

今天頁的狀態判準（`lib/today.ts`）有四種：`due` 今天要做、`done` 今天做了、
`idle` 今天沒它的事（每週型本週稍早做過、里程碑早就完成、累計已達標）、
`mantra` 信念型只看不打卡。**今天做完的要留在今天的清單裡**，不能掉成 idle——
否則做完一件事會讓分母跟著少一，計數從 3/9 變 3/8，看起來像什麼都沒發生。
這條有測試釘住。

## 仍未驗證

- **手機實機觸控沒試過。** 是用 Chrome 把容器寬度壓到手機尺寸驗的，不是真機。
- `milestone` 與 `mantra` 兩型只有單元測試，沒有在真實資料庫上實際操作過。
  `habit` 的每週／每月頻率也只驗過每日。
- 回顧頁只在資料很少（10 筆紀錄）的情況下看過，跨月的折線都還是平的。
  完全空的計劃表開回顧頁不會爆，已實際驗過。
- 今天頁是用一份塞了四種型態、三種頻率、每種狀態各一個的假資料驗的
  （桌機淺色／深色、打卡後計數與鎖定都對）。真機觸控一樣沒試過。
- 部署後的行為（Vercel 上的 server action、環境變數、冷啟）。
